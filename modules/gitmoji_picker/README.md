# Gitmoji Picker

입력 커서 근처에 검색 가능한 8열 Gitmoji 격자를 표시합니다. 커서의 접근성 좌표를 제공하지 않는 앱에서는 마우스 근처에 표시합니다.

```lua
require('modules.gitmoji_picker'):start({
  hotkey = { { 'ctrl', 'option', 'shift' }, 'e' },
  output = 'emoji', -- 'code'이면 :bug: 같은 코드 삽입
})
```

검색어를 입력하고 방향키로 이동한 뒤 Enter를 누르거나 이모지를 클릭합니다. 원래 창으로 돌아가 선택한 이모지와 공백을 입력합니다. Esc는 취소하고 다른 창을 클릭하면 닫힙니다. 이름·코드·영문 설명으로 검색합니다. 한글 입력 상태에서도 물리 키의 영문 이름으로 검색합니다. 한글 검색은 지원하지 않습니다. 방향키는 검색창의 커서 대신 격자 선택을 이동합니다.

기존 window picker와 같은 `hs.canvas`를 사용하며 입력 포커스를 유지합니다. 터미널의 이모지 입력 호환성을 위해 클립보드와 Cmd+V로 삽입하고 1초 뒤 기존 클립보드를 복원합니다. 그 사이 새로 복사한 내용은 덮어쓰지 않습니다. 여러 항목을 동시에 복사한 클립보드는 보존을 위해 삽입을 중단합니다. 8열 × 5행으로 표시하고 방향키 또는 Page Up/Down으로 나머지 항목을 탐색합니다. 앱별 접근성 지원과 텍스트 입력 방식에 따라 위치 또는 삽입 동작에 차이가 있을 수 있습니다. `stop()`으로 단축키·캔버스·키 이벤트를 정리합니다.
